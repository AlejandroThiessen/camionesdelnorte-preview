# Camiones del Norte — static preview

Static snapshot of the Camiones del Norte site, published for mobile review.

**Live:** https://alejandrothiessen.github.io/camionesdelnorte-preview/

Generated by rendering the PHP site and rewriting internal links to flat
`.html` files so they resolve from the GitHub Pages subpath. The `image.php`
resizer is materialised into static `img/w<N>/` renditions, which is what keeps
this at ~130 MB instead of the 1.1 GB of originals.

Preview only: the contact form does not submit (no PHP), and the admin panel is
not included. The live site is https://www.camionesdelnorte.com

`robots.txt` blocks all crawlers so this copy never competes with the real site.
